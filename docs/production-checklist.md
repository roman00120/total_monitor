# Checklist de producción

- [ ] Configurar secretos fuera del repositorio.
- [ ] Crear backup y comprobar restauración en una base de prueba.
- [ ] Aplicar migraciones incrementales desde el servidor.
- [ ] Configurar certificado HTTPS, firewall y URL del cliente.
- [ ] Instalar y probar el servicio con reinicio automático.
- [ ] Verificar /api/v1/health y logs del servicio.
- [ ] Validar mapa TOV452 con documentación oficial y equipo real.
- [ ] Ejecutar prueba de aceptación RS485 y registrar resultados.
- [ ] Probar roles, permisos, históricos, reportes y exportaciones.
- [ ] Ejecutar prueba con múltiples clientes y carga simulada documentando métricas.
- [ ] Confirmar procedimiento de backup, restore, actualización y rollback.
