# Manual de usuario

1. Inicie el servidor y confirme que el endpoint de salud responde.
2. Abra TotalMonitor e indique la URL del servidor en appsettings.json o appsettings.Production.json.
3. Inicie sesión con una cuenta provisionada por el administrador.
4. Use Dashboard para el estado actual, Históricos para consultar por medidor/variable/fecha y Reportes para exportar CSV.
5. Administre medidores, usuarios y permisos solo con el rol correspondiente.

Los tiempos se almacenan en UTC y se muestran en hora local. El modo Simulator es exclusivamente de pruebas; no representa mediciones de un TOV452.
